# Contributing

This repository holds the source code for **Més Enllà del #15M**, a
personal project originally built in 2012 and rebuilt in 2026.

It isn't set up to accept pull requests or direct contributions to this
repository. If you'd like to use, adapt, or build on this project,
forking is welcome and encouraged: it's licensed under
[CC BY-SA 3.0](./LICENSE), so you're free to copy, modify, and reuse it,
including commercially, as long as you credit the original author and
share your version under the same license.

Bug reports and questions are welcome via Issues, but please don't expect
pull requests to be merged here.
